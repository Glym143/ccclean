# ccclean

**Хирургически точная очистка контекста для сессий [Claude Code](https://docs.anthropic.com/en/docs/claude-code).**
Обрезает самые старые сообщения в диалоге, чтобы освободить окно контекста — с шагом подтверждения и необязательной сводкой того, что будет удалено.

## Зачем ccclean

Длинные сессии Claude Code заполняют окно контекста, и работать становится
труднее: модель упирается в свой лимит, а авто-компакт срабатывает в неподходящий
момент и без разбора схлопывает всё подряд. `ccclean` даёт вам **точный
контроль**: вы сами решаете, сколько токенов освободить и какой именно старый
кусок диалога выбросить — предварительно увидев его краткую сводку. Текущая
(свежая) часть диалога остаётся нетронутой.

В отличие от встроенного `/compact` (который сжимает *весь* диалог в сводку),
`ccclean` просто **отрезает самое старое начало** активной ветки, сохраняя
последние сообщения дословно.

## Возможности

- ✂️ **Точная обрезка** — вы указываете объём (`10k`, `50k`, `1.5m`), и
  инструмент удаляет старые сообщения с начала так, чтобы освободить **не меньше**
  запрошенного.
- 🔢 **Честный подсчёт токенов** — по умолчанию через официальный API Anthropic
  `count_tokens` (точно) либо офлайн через `tiktoken` (`--fast`). Учитываются
  текст, `thinking`, вызовы инструментов и **изображения**.
- 📋 **Сводка удаляемого (опционально)** — с флагом `--summary`, прежде чем
  что-либо удалять, показывает краткую сводку куска (через DeepSeek), чтобы вы
  понимали, что теряете. По умолчанию выключено.
- 📊 **Реальная загрузка окна** — показывает фактический размер контекста из логов
  (`usage`), включая системный промпт, схемы инструментов, MCP и `CLAUDE.md`.
- 🗂 **Интерактивный выбор сессии** — без аргументов открывает список диалогов
  (через `fzf`, с поиском по заголовку), чтобы не приходилось помнить id.
- 🔓 **Снимает блокировку «достигнут лимит контекста»** — Claude Code определяет
  лимит по `usage` последнего ответа, а не пересчитывает обрезанные сообщения.
  После обрезки ccclean понижает этот счётчик на `usage_subtract`
  (по умолчанию `200k`, ключ в `config.json`) — заметно ниже того, что было реально
  удалено, поэтому авто-компакт не срабатывает до первого запроса после очистки.
  Реальный контекст всё ещё ниже лимита, так что сервер принимает запрос, и
  Claude Code пересчитывает счётчик по фактическим данным.
- 💾 **Безопасность** — автоматический бэкап перед каждой обрезкой, проверка
  целостности, защита от удаления всего диалога и корректная пересшивка корня.

## Установка

Нужны **Python 3.8+** и `pip`. Всё остальное (`tiktoken`, `anthropic`,
`fzf`) инструмент устанавливает сам при первом запуске.

```bash
git clone https://github.com/Glym143/ccclean.git
cd ccclean
./install.sh
```

`install.sh`:

- делает `ccclean.py` исполняемым;
- создаёт симлинк `ccclean` в первой доступной для записи директории из `PATH`
  (`/opt/homebrew/bin`, `/usr/local/bin` или `~/.local/bin`) — без sudo;
- создаёт конфиг `~/.config/ccclean/config.json` (режим `600`).

> Если выбран `~/.local/bin`, но его нет в `PATH`, добавьте в
> `~/.zshrc` / `~/.bashrc`:
> `export PATH="$HOME/.local/bin:$PATH"`

### Ключи API

Поместите ключи в `~/.config/ccclean/config.json`:

```json
{
  "deepseek_api_key": "sk-...",
  "anthropic_api_key": "sk-ant-..."
}
```

- **`anthropic_api_key`** — точный подсчёт токенов (режим по умолчанию).
  Получить можно на <https://console.anthropic.com/> → API Keys.
- **`deepseek_api_key`** — сводки удаляемого куска.
  Получить можно на <https://platform.deepseek.com/> → API Keys.

Также можно задать их через переменные окружения (они в приоритете):
`ANTHROPIC_API_KEY`, `DEEPSEEK_API_KEY`.

Без ключа Anthropic инструмент автоматически переходит на офлайн-`tiktoken`
(приблизительно). Без ключа DeepSeek сводка пропускается.

## Использование

```bash
ccclean                       # pick a session from the list + free 50k (default)
ccclean 30k                   # pick a session + free 30k
ccclean <session-id>          # a specific session + free the default amount
ccclean <session-id> 30k      # a specific session + free 30k
ccclean <session-id> --keep 200k     # keep roughly the last 200k tokens
ccclean <session-id> 50k --dry-run   # show the plan, change nothing
ccclean <session-id> 100k --fast     # fast offline counting (tiktoken)
```

Объём задаётся позиционно (`30k`, `50000`, `1.5m`) или флагом `--free` / `--keep`
(флаг имеет приоритет). Порядок аргументов не важен. `session-id` можно
сокращать (как в списке выбора). Полный список флагов: `ccclean -h`.

Если объём не указан, используется `default_free` из
`~/.config/ccclean/config.json` (при установке — `50k`; встроенное значение по
умолчанию, если конфига нет, — `10k`) — поменяйте его там, чтобы задать значение
по умолчанию раз и навсегда.

После очистки возобновите сессию:

```bash
claude --resume <session-id>
```

## Автоматическая очистка (хук + `ccclaude`)

Чтобы не чистить вручную, есть автоматический режим: когда контекст заполняется и
Claude Code запускает компакт, хук перехватывает его и вместо сжатия с потерями
запускает `ccclean`, после чего сессия перезапускается уже разгруженной.

`install.sh` настраивает всё за вас:

- устанавливает команду-обёртку **`ccclaude`**;
- размещает хук в `~/.claude/hooks/ccclean-hook.sh`;
- регистрирует его в `~/.claude/settings.json` для события `PreCompact`, но только
  для **авто**-компакта (ручной `/compact` не трогается — если вы запустили его
  сами, значит компакт вам и был нужен);
- включает `autoCompactEnabled: true` (нужно, чтобы хук срабатывал сам);
- задаёт `autoCompactWindow: 1000000` — поднимает порог авто-компакта ближе к
  реальному потолку модели (Claude Code вычисляет порог как
  `window − ~33k`), чтобы «достигнут лимит контекста» не срабатывало
  преждевременно.

> Как это устроено внутри Claude Code (по результатам реверса бандла): блокировка
> наступает, когда `usage` последнего ответа ≥ `auto-compact-window −
> output_reserve(≤20k) − 13k`. Поэтому помогают два рычага: поднять окно
> (`autoCompactWindow`, делает install.sh) и понизить счётчик после очистки
> (`usage_subtract`, делает ccclean).

**Как пользоваться:** запускайте Claude Code через обёртку (в терминале):

```bash
ccclaude --resume <session-id>      # instead of `claude --resume <session-id>`
```

Цикл при заполнении:

1. Claude Code упирается в лимит → запускает авто-компакт.
2. Хук `ccclean-hook.sh` помечает сессию и завершает `claude` (компакт
   отменён).
3. Обёртка `ccclaude` видит метку → ждёт ~2 с → `ccclean <id> --force` →
   перезапускает и сразу отправляет промпт: `claude --resume <id> "continue"`.

Размер обрезки за цикл задаётся (в порядке приоритета):

1. переменной окружения `CCCLEAN_FREE` (разово),
2. ключом `default_free` в `~/.config/ccclean/config.json` (постоянно),
3. встроенным значением по умолчанию `10k`.

```bash
CCCLEAN_FREE=300k ccclaude --resume <id>   # one-off, unload an overflowing session
```

```json
// ~/.config/ccclean/config.json — change the default once and for all
{ "default_free": "30k" }
```

**Ограничения:**

- Работает **в терминале**, а не внутри VS Code (хук завершает процесс
  `claude`; у VS Code другая модель процессов).
- Если сессия у самого потолка, небольшая обрезка (`10k`) может не вывести её из
  лимита за один цикл — увеличьте `CCCLEAN_FREE` для разовой разгрузки.

### Проактивный режим (`clean_at`)

Чтобы вы вообще никогда не упирались в «достигнут лимит контекста», есть второй
хук — на событие `Stop` (после каждого ответа). Он читает текущий `usage` из
транскрипта, и если тот выше порога **`clean_at`** (ключ в `config.json`,
например `"940k"`), заранее запускает тот же цикл очистки (завершение → `ccclean` →
перезапуск) — пока ещё в пределах лимита. Так блокировка не наступает никогда.
Режим включается наличием `clean_at` в конфиге.

### Автопродолжение (`resume_prompt`)

После перезапуска обёртка не просто открывает сессию — она **сразу отправляет в
неё промпт**, чтобы работа продолжалась без вашего участия:

```bash
claude --resume <id> "continue"     # claude sends the prompt right at startup
```

Текст задаётся ключом **`resume_prompt`** в `config.json` (по умолчанию
`"continue"`):

```json
{ "resume_prompt": "continue from where you left off" }
```

Пустая строка (`""`) → просто возобновление, без авто-отправки.

### Безопасность хука

Хуки `Stop` / `PreCompact` **завершают процесс `claude`**, поэтому действуют
только в сессиях, запущенных через обёртку `ccclaude` (которая выставляет
`CCCLEAN_WRAPPED=1`). В обычных сессиях (`claude`, VS Code) хуки бездействуют и
ничего не трогают.

## Как это работает

1. Находит файл сессии (по id или через интерактивный выбор).
2. Восстанавливает **активную ветку** диалога — цепочку от последнего сообщения
   назад по `parentUuid` до корня (именно она и загружается в контекст).
3. Считает токены (Anthropic API — точно; `--fast` — tiktoken).
4. Находит точку обрезки под запрошенный объём, выравнивая её по границе
   пользовательского сообщения (отрезает не меньше запрошенного).
5. Запрашивает подтверждение (а с `--summary` — краткую сводку удаляемого куска
   через DeepSeek).
6. Создаёт бэкап `*.jsonl.bak-<date>`, удаляет старые сообщения, пересшивает
   корень.
7. Проверяет целостность результата.

## Для AI-агентов

Если инструмент запускает агент (а не человек), учтите:

- **Неинтерактивный режим:** `-y` (без подтверждений), `--fast` (без сети,
  офлайн-подсчёт). Сводка DeepSeek по умолчанию ВЫКЛЮЧЕНА — включите её флагом
  `--summary`. Сессию **обязательно** нужно указать явным `session-id` — без него
  запустится интерактивный выбор и зависнет.
  ```bash
  ccclean <session-id> 50k --fast -y
  ```
- **Предпросмотр без изменений:** `--dry-run` — печатает план («освободит ≈ X»,
  «оставит ≈ Y») и выходит, ничего не трогая. Удобно для оценки.
- **Гарантия:** реально обрезает **не меньше** запрошенного объёма; число
  «освободит ≈» в выводе точно соответствует фактическому удалению.
- **Только активная ветка:** инструмент трогает лишь текущую линейную цепочку
  диалога. Системный промпт, схемы инструментов, MCP и `CLAUDE.md` входят в
  контекст, но обрезкой **не** удаляются (их нет в `.jsonl`).
- **Безопасно по умолчанию:** бэкап создаётся всегда (отключается флагом
  `--no-backup`). Для отката скопируйте `*.jsonl.bak-*` поверх `*.jsonl`.
- ⚠️ **Запускайте только когда целевая сессия ЗАКРЫТА:** открытый процесс
  Claude Code перезапишет файл из памяти и затрёт ваши изменения. Инструмент
  проверяет это через `lsof` и **откажется** обрезать открытую сессию (обойти
  можно флагом `--force`).

## Предостережения

- **Запускайте только когда очищаемая сессия закрыта** (проверяется через `lsof`;
  инструмент отказывается обрезать открытую сессию, обойти можно флагом
  `--force`).
- Бэкап создаётся автоматически рядом с файлом сессии перед каждой обрезкой.
- Подсчёт токенов через `tiktoken` (`--fast`) приблизителен (занижает на
  кириллице); для точных чисел используйте режим по умолчанию (Anthropic API).
