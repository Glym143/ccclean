# ccclean

Утилита для очистки контекста сессий Claude Code. Удаляет старые сообщения
с начала диалога, чтобы освободить место в окне контекста, — с предварительным
кратким резюме удаляемого фрагмента (через DeepSeek) и подтверждением.

Работает напрямую с `.jsonl`-файлами сессий в `~/.claude/projects/`.

---

## Что нужно (требования)

- **Python 3.8+** (есть на macOS/Linux из коробки или ставится пакетным менеджером)
- **pip** (обычно идёт вместе с Python)
- Доступ в интернет — для точного подсчёта токенов (Anthropic API) и резюме (DeepSeek)

Всё остальное ставится автоматически при первом запуске:
- `tiktoken` и `anthropic` (Python-пакеты) — `ccclean` доустановит сам через pip;
- `fzf` (удобный выбор сессии) — `ccclean` предложит поставить через `brew`/`apt`/`dnf`.

## Установка на новом ПК

### 1. Перенеси папку

Скопируй на новый компьютер всю папку проекта (git, флешка, scp — как удобно).
В ней уже лежит всё необходимое:

```
ccclean.py      # сама утилита
install.sh      # установщик
config.json     # твои API-ключи (готовый конфиг)
README.md       # эта инструкция
```

> ⚠️ `config.json` содержит твои API-ключи. Передавай папку только по доверенному
> каналу и не выкладывай её в публичный git.

### 2. Запусти установщик

```bash
cd /путь/к/папке
chmod +x install.sh
./install.sh
```

Что делает `install.sh`:
- делает `ccclean.py` исполняемым;
- создаёт симлинк `ccclean` в первом доступном каталоге из `PATH`
  (`/opt/homebrew/bin`, `/usr/local/bin` или `~/.local/bin`) — без sudo;
- **копирует `config.json` из папки в `~/.config/ccclean/config.json`** (права `600`).
  Если конфиг там уже есть — не трогает его.

Больше ничего вписывать не нужно — ключи уже в `config.json`.

> Если установщик выбрал `~/.local/bin`, а его нет в `PATH`, добавь строку
> в `~/.zshrc` / `~/.bashrc`:
> ```bash
> export PATH="$HOME/.local/bin:$PATH"
> ```
> и перезапусти терминал.

### 3. Проверь

```bash
ccclean --help     # справка
ccclean            # выбор сессии + срез 10k по умолчанию
```

---

### Про ключи (если нужно поменять)

Конфиг живёт в `~/.config/ccclean/config.json`:

```json
{
  "deepseek_api_key": "sk-...ключ DeepSeek...",
  "anthropic_api_key": "sk-ant-...ключ Anthropic..."
}
```

- **`anthropic_api_key`** — точный подсчёт токенов (режим по умолчанию).
  Получить: <https://console.anthropic.com/> → API Keys.
- **`deepseek_api_key`** — резюме удаляемого фрагмента.
  Получить: <https://platform.deepseek.com/> → API Keys.

Ключи можно переопределить переменными окружения (они в приоритете):

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export DEEPSEEK_API_KEY="sk-..."
```

Если ключа Anthropic нет — `ccclean` сам переключится на офлайн-подсчёт `tiktoken`
(приблизительный). Если нет ключа DeepSeek — пропустит резюме.

## Использование

```bash
ccclean                       # выбор сессии из списка + срез 10k (по умолчанию)
ccclean 30k                   # выбор сессии + срез 30k
ccclean <session-id>          # конкретная сессия + срез 10k
ccclean <session-id> 30k      # конкретная сессия + срез 30k
ccclean <session-id> --keep 200k     # оставить последние ~200k токенов
ccclean <session-id> 50k --dry-run   # только показать план и резюме, ничего не менять
ccclean <session-id> 100k --fast     # быстрый офлайн-подсчёт (tiktoken вместо API)
```

Объём задаётся позиционно (`30k`, `50000`, `1.5m`) либо флагом `--free`/`--keep`
(флаг имеет приоритет). Порядок аргументов не важен.

Полный список флагов: `ccclean -h`.

---

## Как это работает (кратко)

1. Находит файл сессии (по id или через интерактивный выбор).
2. Восстанавливает активную ветку диалога (цепочка по `parentUuid`).
3. Считает токены (Anthropic API — точно; `--fast` — tiktoken приблизительно).
4. Находит точку реза по нужному объёму (на границе сообщения пользователя).
5. Делает краткое резюме удаляемого фрагмента через DeepSeek.
6. Спрашивает подтверждение.
7. Создаёт бэкап `*.jsonl.bak-ДАТА`, удаляет старые сообщения, переподшивает корень.
8. Проверяет целостность результата.

После очистки возобнови сессию:
```bash
claude --resume <session-id>
```

---

## Важно

- **Запускай только при ЗАКРЫТОЙ** очищаемой сессии. Если она открыта, работающий
  процесс Claude Code перезапишет файл из памяти, и правки потеряются.
- Перед каждой резкой автоматически создаётся бэкап рядом с файлом сессии.
  Откатить: скопировать `*.jsonl.bak-...` обратно поверх `*.jsonl`.
- **Не коммить** `~/.config/ccclean/config.json` и `*.bak-*` в git — там ключи и копии диалогов.
